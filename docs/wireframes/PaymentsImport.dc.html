Import payments from QuickBooks (CSV)

In QuickBooks, run a report of payments received and export it to CSV. Paste it here. Billdable proposes a pay app for each payment; nothing is recorded until you tick and apply. A check number already in Billdable is skipped, so importing the same file twice is safe.
